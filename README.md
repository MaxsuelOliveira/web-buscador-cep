## Descricao

Aplicacao web simples para consultar enderecos brasileiros a partir de um CEP, consumindo a API publica ViaCEP.

## Demonstracao Visual

| Desktop | Mobile |
| --- | --- |

## Funcionalidades

- Consulta de CEP com ViaCEP
- Validacao basica do campo de busca
- Renderizacao dos dados de endereco em cartao
- Layout responsivo
- Separacao de componente visual em JavaScript

## Tecnologias

- HTML5
